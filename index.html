Performance Specifications
Metric What it measures Good Needs Improvement Poor
LCP
 Largest Contentful Paint measures loading performance / perceived load speed
Time until the largest content element is rendered
 < 2.5 seconds > 2.5 and < 4.0 seconds > 4.0 seconds
INP
 Interaction to Next Paint measures page responsiveness after user input
Latency of user interactions throughout the page lifecycle
 < 200 milliseconds > 200 and < 500 milliseconds > 500 milliseconds
CLS
 Cumulative Layout Shift measures unexpected visual movement / visual stability
Sum of all individual layout shift scores
 < 0.1 > 0.1 and < 0.25 > 0.25
